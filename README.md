## 📖 專案簡介

傳統的技術名詞解說往往充斥著艱澀的數學公式與死板的定義，導致初學者望而卻步。  
**AI 知識全景與實戰指南** 是一套**單一檔案原生運作、雙模式切換**的互動學習教材，將現代生成式 AI 與 Agent 開發核心知識提煉為四大演進階段，結合白話生活比喻、四格漫畫、動態互動沙盒與 20 題能力診斷測驗，幫助你在最短時間內建立完整、立體且能落地的 AI 心智模型。

---

## 🚀 核心特色亮點

### 1. 🖥️ 主題式投影片 (Slide-Deck) 與長圖雙模式
- **簡報投影模式 (`Slide Mode`)**：將內容切分為 15 張專注投影片，頁面獨立居中，去除資訊過載，極度適合教學、分享與個人沉浸研讀。
- **連續滾動模式 (`Continuous Mode`)**：一鍵切換為傳統長篇閱讀視野，方便快速縱覽全文。
- **完整鍵盤快捷鍵支援**：
  | 快捷鍵 | 功能描述 |
  | :--- | :--- |
  | `←` / `→` 或 `Space` | 上一張 / 下一張投影片 |
  | `F` | 切換全螢幕投影模式 |
  | `T` | 展開 / 收合側邊目錄導航抽屜 |
  | `M` | 切換簡報模式 / 連續長圖模式 |

### 2. 🎯 20 題課前 AI 能力診斷測驗
- 涵蓋「文字接龍與機率、Prompt 工程、本地 Agent 工具呼叫、多 Agent 分工管線」四大維度。
- 每題提供詳細的即時答題解析，完成後自動評估你的 AI 認知位階（入門體驗者 L1 ➔ 實戰架構師 L4），並指引專屬閱讀起點。

### 3. 🎨 四格情境漫畫與白話直觀比喻
- 告別抽象理論！每一單元均以精準、幽默的四格漫畫切入：
  - **單元 01**：大腦思考 vs 統計文字接龍（文字接龍的本質）
  - **單元 02**：模糊指示 vs 規格化需求（如何精準調教 AI 實習生）
  - **單元 03**：只能聊天 vs 長出手腳（Agent 本地檔案與工具操作）
  - **單元 04**：一人分飾多角 vs 專業流水線（多 Agent 的管線分工）

### 4. 🧪 零門檻互動沙盒模擬器
- **LLM 機率沙盒**：即時調整 `Temperature` 與 `Top-P`，親眼觀察模型字詞機率分布變化。
- **Prompt 演練場**：動態套用 Role-Task-Context-Constraints 結構化模板，即時查看 Prompt 質變。
- **Tool Calling 時序模擬**：直觀視覺化模型如何生成呼叫指令、本地執行環境回傳資料、最終生成答案的閉環。
- **多 Agent 管線流水線**：模擬「規劃者 ➔ 程式員 ➔ 測試員 ➔ 審查員」協同作業過程。

### 5. 📚 31 個生活化核心名詞百科
- 收錄 31 個最關鍵的名詞解析，每一張卡片嚴格遵循 **A-B-C-D 四維標準架構**：
  - **[A] 生活直白比喻**：用廚師、實習生、字典等日常物件瞬間理解。
  - **[B] 底層運作原理**：拆解關鍵技術機制與資料流向。
  - **[C] 實戰應用範例**：展示在真實開發與產品中的應用場景。
  - **[D] 關鍵避坑指南**：點出最常見的誤區與工程資安風險。

### 6. 🏆 4 大思維躍遷與實戰行動清單 (Cheat Sheet)
- 結尾總結從使用者到 AI 架構師的核心心態轉變。
- 附帶「即刻落地 Check-list」，檢驗你的 Prompt、Agent 安全權限與錯誤處理策略。

## 💻 本地離線開啟方式

本專案採用**純前端零依賴架構**（Vanilla HTML5 + CSS3 + ES6 JavaScript），不需 Node.js 或 Python 伺服器即可運作。

1. **Clone 本專案至本機**：
   ```bash
   git clone https://github.com/kentchuang/ai-guide.git
   cd ai-guide
   ```
2. **直接以瀏覽器開啟**：
   - 雙擊開啟 `index.html` 或 `ai_knowledge_guide_interactive.html`。
   - 或使用 VS Code 的 **Live Server** 擴充套件啟動。

## 🛠️ 技術棧與架構設計

- **核心技術**：原生 HTML5、CSS 現代變數系統 (CSS Custom Properties)、Flexbox & CSS Grid、Vanilla JavaScript (ES6+)。
- **無任何重量級第三方框架**：零 npm 依賴、零 Webpack/Vite 編譯負擔，秒開即看。
- **純向量 SVG 圖示與自適應字體**：支援高解析度 Retina 螢幕與行動裝置縮放。
- **GitHub Actions 自動化部署**：推送至 `main` 分支時由 GitHub Pages 自動託管。
